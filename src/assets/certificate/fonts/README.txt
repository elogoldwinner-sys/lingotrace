Optional: exact fonts for the certificate.

The certificate template was designed in Canva with the "Cakerolli" font, which can't be bundled
here. By default LingoTrace draws the student name and the reason with the closest free fonts
(Patrick Hand / Baloo Bhaijaan 2 from Google Fonts).

If you own the Cakerolli font files, drop them in this folder with these exact names and the
certificate will use them automatically (no code change needed):

  Cakerolli-Bold.ttf      (student name)
  Cakerolli-Regular.ttf   (reason + stat chips)

.otf / .woff / .woff2 also work.
